# Bicycle-rentals
Inferential modeling of bicycle rentals in Washington, D.C. (2011–2012)

Inferential analysis of the dataset containing information on bicycle rentals within the urban area of Washington, D.C. in 2011 and 2012. The project includes inferential analysis with a single variable (inference for a central‐tendency parameter, paired‐sample tests, functional tests including the Kolmogorov and chi‐square tests), inferential analysis with two variables (inference for central‐tendency parameters, correlation, analysis of variance), various linear regression models (transformations‐based regressions, Poisson regressions, logistic regressions), multiple regression models (generalized additive models and multiple logistic regression) and smoothing methods for deriving one or two‐variable density functions.
All statistical analyses were performed in R, and the final document was produced in LaTeX.

#Dataset
The dataset used in this project was obtained from https://www.kaggle.com/datasets/archit9406/bike-sharing?select=day.csv by Archit9406.
The file's original name is day.csv
